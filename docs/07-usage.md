# 使用文档

## 用户角色说明

v2.0.0 起角色分三级，权限可以逐项配置（见下方「权限配置」）。

### 超级管理员（Super Admin）
- 拥有全部 26 项权限
- **用户管理**：创建、编辑、删除用户，分配角色与逐项权限
- **页面配置 / 版本更新**：系统级配置仅超管可见
- **审计日志**：查看全部关键操作留痕

### 管理员（Admin）
- **会员中心**：会员档案、微信绑定审核、绑定码、推送日志
- **台网历史**：查看、编辑、软删与恢复、回收站
- **运营中心**：台网统计、数据看板、主控轮值、台网预告
- **设备库 / 微信配置**
- ⚠️ 不再拥有用户管理权限（不能给自己或他人提权）

### 主控（User）
- **主控台**：创建会话、录入与修改记录、实时协作
- **运营中心**：查看台网统计、看板、轮值与预告
- 不能删除记录、不能进入会员中心与系统管理

## 权限配置（超级管理员）

1. 进入「系统管理 → 用户管理」
2. 找到目标账号，点「编辑」
3. 选择角色（角色只决定默认勾选），再在下方权限矩阵里**逐项勾选**
4. 点「按角色默认值重置」可恢复该角色模板
5. 保存后 **立即生效**，对方刷新页面即可看到新菜单

内置保护：最后一位超管不可删除或降级；超管账号只能由超管操作；不能删除当前登录账号。

## 个人中心（会员 / 微信用户）

会员从公众号菜单或推送消息进入 `/me`，用微信静默授权登录，**90 天内免登**。

| 页签 | 内容 |
|---|---|
| 我的记录 | 历次参与场次、收/报信号、QTH、设备、天线；每页 5 条，可翻页 |
| 档案 | 编号、姓名、QTH、设备、天线、功率；执照编号、类别、操作证书、发证机关、发证与到期日期，保存即生效并留痕 |
| 绑定 | 绑定状态、绑定呼号、绑定时间；可自助解绑或重新绑定 |
| 推送 | 本人的模板消息送达记录 |

概览页包含：

- **排名徽章**：右上角显示**本月排名**与较上月变化；第 1 名金、2–3 名银、4–10 名铜勋章，50 名以后不显示
- **四格数据**：本月排名 / 本月台网（附台网率）/ 最近一次 / 连续参与天数（附较上月场次变化）
- **统计口径**：概览只展示月度数据，累计次数与年度汇总仅在年度报告中出现
- **主控记录卡**（仅主控账号）：显示主控场次与累计录入条数
- **执照卡**：脱敏显示，点小眼睛查看完整编号；到期 90 天内转黄、30 天内转红
- **更多服务**：我的证书 / 台网查询 / 台网预告
- **台网规则**：首次进入自动弹前 3 条，之后从「更多服务」下方的入口查看全部（内容由后台 `member_rules` 维护）

**注意**：呼号是身份标识，会员不能自助修改，需联系管理员；其余字段均自助维护。

## 操作指南

### 1. 登录系统
1. 访问系统地址
2. 输入用户名和密码
3. 点击"登录"按钮

### 2. 创建台网会话
1. 点击"创建新会话"
2. 选择主控人员（可从现有用户中选择）
3. 填写主控信息（设备、天线、QTH）
4. 设置会话时间（北京时间）
5. 点击"创建会话"

### 3. 录入台网记录
1. 进入会话详情页
2. 在呼号输入框中输入呼号（支持自动联想）
3. 系统自动填充历史数据
4. 确认或修改信息
5. 点击"添加记录"或按 Ctrl+Enter

### 4. 导出 Excel
1. 进入会话详情页
2. 点击"导出Excel"按钮
3. 系统自动生成并下载 Excel 文件

### 5. 查询呼号
1. 点击顶部"呼号查询"
2. 输入呼号
3. 点击"查询"按钮
4. 查看该呼号的所有历史记录
