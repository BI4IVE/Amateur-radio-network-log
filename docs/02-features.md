# 功能特性

| 模块 | 核心能力 |
|------|----------|
| 🔐 **用户认证与权限** | 超级管理员 / 管理员 / 主控三级角色；26 项权限点可逐项勾选；不区分大小写登录；多主控协作 |
| 🛡️ **三级权限**（v2.0.0） | 角色只作默认模板，超管可在用户管理里逐项增删权限；改完立即生效；用户管理（建号/改角色/重置密码）仅超管可用 |
| 🪪 **微信个人中心**（v2.0.0） | `/me` 页：公众号静默授权、90 天免登；我的记录（分页）、参与统计、档案与执照自助维护、绑定管理、推送记录 |
| 👥 **会员中心**（v2.0.0） | 会员档案分页 + 状态筛选（已绑定 / 待审核 / 未绑定 / 执照临期）；微信绑定审核；绑定码；会员对照表；推送日志；缺失档案一键补建 |
| 🧾 **审计日志**（v2.0.0） | 台网删除与恢复、会员档案修改（区分用户自助与管理员）均留痕；支持按动作筛选与关键字搜索 |
| 📲 **微信公众号推送**（v1.5.21） | 台网回执模板消息；成功留痕与同场次去重；`access_token` 失效自动重试；点击消息直达个人中心 |
| 📝 **台网会话管理** | 创建会话、记录主控信息（呼号/设备/天线/QTH）；可编辑时限后台可配置（默认 6 小时，0 表示不限制）；活跃会话列表 |
| 📊 **台网记录录入** | 呼号/设备自动联想、历史联想；Ctrl+Enter 快捷录入；必填校验；SSE 实时协作 |
| 🗂️ **参与人员库** | 呼号/姓名/设备等信息管理；呼号搜索自动填充；录入即同步更新 |
| 🔧 **设备库**（v1.5.0） | 独立设备库；增删改查；Excel/CSV 批量导入导出；历史一键导入；录入自动同步 |
| 📜 **台网历史管理**（v1.5.0） | 管理员免过期编辑任意记录；指定日期新增；Excel 导入导出；会话管理 |
| 📥 **Excel 导出** | xlsx-js-style 带样式导出（标题加粗居中、表头蓝底白字、自动列宽行高） |
| 🔍 **呼号查询** | 按呼号查看全部历史记录、详细信息与参与次数统计 |
| 📈 **台网统计** | 历史会话浏览、会话详情、CSV 导出、多维度报表 |
| ⚙️ **页面配置** | 后台动态修改标题/版本号/联系方式/台网可编辑时限等；实时生效；按通用/登录/首页/会话详情分类 |
| 🛠️ **管理工具** | 用户管理、弹窗编辑、批量操作、CSV 导出、多条件搜索筛选 |
| 🌐 **多语言与时区** | 全中文界面；统一北京时间（UTC+8）；呼号自动转大写 |
| 🎨 **界面优化** | shadcn/ui 现代化设计；响应式布局；顶部导航 + 可收缩侧边栏 |
| 📡 **实况大屏**（v1.5.16） | `/live` 页面，SSE 实时滚动在网呼号与最新记录；支持竖屏大屏（默认大屏M / 手机版），适配手机观看，电脑版切换在右上角、竖屏切换在页面底部 |
