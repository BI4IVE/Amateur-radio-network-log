Features

一个台网，全部搞定

从开台网、录入、协作到大屏、统计、证书，覆盖台网日志的完整闭环。

台网会话管理

一键创建会话并登记主控呼号、设备、天线与 QTH；支持台网预告与开台倒计时，历史场次随时回看。

呼号联想快速录入

输入呼号自动联想参与人员库与历史记录，设备、QTH 一键填充；Ctrl+Enter 快捷提交，录入飞快。

SSE 多主控实时协作

基于 Server-Sent Events，多主控同时录入即时互见，30 秒心跳保活，不怕断网丢记录。

参与人员库

集中维护呼号、姓名、设备与 QTH 资料，支持 Excel 批量导入；录入记录即自动沉淀，越用越聪明。

设备库管理

独立设备库，支持增删改查与 Excel/CSV 批量导入导出，还可一键从历史记录收编设备，统一口径。

带样式 Excel 导出

xlsx-js-style 生成排版规范的报表：标题加粗居中、表头蓝底白字、列宽行高自动适配，可直接归档交付。

呼号查询与参与证书

按呼号查看近一年全部台网记录与参与次数，自动生成可打印的参与证书，呼号直达 URL 方便分享。

台网统计与数据看板

总会话数、参与人数、呼号排行、按周活跃分布一目了然；支持区间筛选与 CSV 导出，运营决策有据可依。

实况大屏（横竖屏）

/live 页面 SSE 实时滚动在网呼号与最新记录，支持电脑横屏与手机竖屏，直接投屏电视、会场大屏。

角色权限与安全

管理员 / 主控双角色分级，后台按角色自动过滤菜单；登录态加密 Cookie，操作均有审计留痕，回收站可恢复。

页面配置实时生效

站点文案、版本号、联系方式、可编辑时限等后台在线修改，保存即时生效无需重启，不用改代码即可运营。

台网历史管理

管理员可补录与修正任意历史场次，支持指定日期整场新增、Excel/CSV 批量导入，历史数据一键迁移入库。

Quick Start

5 分钟跑起来

环境要求：Node.js 24+、pnpm 9+、PostgreSQL 14+，内存 ≥ 2GB。支持宝塔面板、传统 Linux 与 Docker 多种部署方式。

  • 克隆仓库并安装依赖
  • 创建数据库并配置 .env（含 JWT_SECRET）
  • 执行建表迁移，首次访问自动初始化管理员
  • 启动后访问 http://localhost:5000
完整使用说明书 README · 项目文档 
# 1. 克隆
git clone https://github.com/BI4IVE/Amateur-radio-network-log.git
cd Amateur-radio-network-log

# 2. 依赖与数据库
pnpm install
createdb radio_network_log   # PostgreSQL
cp .env.example .env             # 填 DATABASE_URL/JWT_SECRET

# 3. 建表并启动
pnpm db:push
pnpm dev
# → http://localhost:5000
