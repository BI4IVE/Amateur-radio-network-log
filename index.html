Features

从开台到归档，覆盖台网完整闭环

录入、协作、呈现、管理一个不少 —— 为“业余、但绝不业余”的每一次台网而生。

01

台网会话管理

一键创建会话并登记主控呼号、设备、天线与 QTH；支持台网预告与开台倒计时，历史场次随时回看。

02

呼号联想录入

输入呼号自动联想参与人员库与历史记录，设备、QTH 一键填充；Ctrl+Enter 快捷提交，录入飞快。

03

SSE 多主控协作

基于 Server-Sent Events，多主控同时录入即时互见，30 秒心跳保活，不怕断网丢记录。

04

参与人员库

集中维护呼号、姓名、设备与 QTH 资料，支持 Excel 批量导入；录入记录自动沉淀，越用越聪明。

05

设备库管理

独立设备库，支持增删改查与 Excel/CSV 批量导入导出，还可一键从历史记录收编设备，统一口径。

06

Excel 归档导出

xlsx-js-style 生成排版规范的报表：标题加粗居中、表头蓝底白字、列宽行高自动适配，可直接归档交付。

07

呼号查询与证书

按呼号查看近一年全部台网记录与参与次数，自动生成可打印的参与证书，呼号直达 URL 方便分享。

08

统计与数据看板

总会话数、参与人数、呼号排行、按周活跃分布一目了然；支持区间筛选与 CSV 导出，运营决策有据可依。

09

实况大屏投放

/live 页面 SSE 实时滚动在网呼号与最新记录，支持电脑横屏与手机竖屏，直接投屏电视、会场大屏。

10

权限与审计安全

管理员 / 主控双角色分级，后台按角色自动过滤菜单；登录态加密 Cookie，操作均有审计留痕，回收站可恢复。

11

页面配置实时生效

站点文案、版本号、联系方式、可编辑时限等后台在线修改，保存即时生效无需重启，不用改代码即可运营。

12

台网历史管理

管理员可补录与修正任意历史场次，支持指定日期整场新增、Excel/CSV 批量导入，历史数据一键迁移入库。

Quick Start

5 分钟跑起来

环境要求：Node.js 24+、pnpm 9+、PostgreSQL 14+，内存 ≥ 2GB。支持宝塔面板、传统 Linux 与 Docker 多种部署方式。

  • 克隆仓库并安装依赖git clone + pnpm install
  • 创建数据库并配置 .env含 DATABASE_URL 与 JWT_SECRET
  • 执行建表迁移首次访问自动初始化管理员
  • 启动并访问http://localhost:5000 即可开台网
terminal · zsh
# 1. 克隆
git clone https://github.com/BI4IVE/Amateur-radio-network-log.git
cd Amateur-radio-network-log

# 2. 依赖与数据库
pnpm install
createdb radio_network_log   # PostgreSQL
cp .env.example .env             # 填 DATABASE_URL / JWT_SECRET

# 3. 建表并启动
pnpm db:push
pnpm dev
# → http://localhost:5000

FAQ

常见问题

系统需要什么样的运行环境？
Node.js 24+、pnpm 9+、PostgreSQL 14+，内存建议 ≥ 2GB。既可跑在宝塔面板等传统主机，也可以用项目内置的 docker-compose.yml 一键拉起全套环境。
开一场台网，主控要操作几步？
三步：① 创建会话并登记主控呼号/设备/QTH；② 友台上联后录入呼号（联想自动带出资料），回车即提交；③ 结束时可一键导出带样式 Excel，或开启实况大屏现场展示。更多细节见使用说明书“主控台”章节。
历史数据能批量迁入吗？怎么备份？
可以。后台“台网历史管理”支持指定日期整场新增与 Excel/CSV 批量导入，旧站数据可一次性迁移入库。日常备份推荐使用数据库定时导出，配合系统自带的带样式 Excel 报表即可双保险。
系统开源吗？可以商用或自部署吗？
MIT License 完全开源，代码在 GitHub 全量可见。允许自由使用、修改、商用与自部署；部署与升级路径详见仓库 docs/05-deployment.md 与在线说明书“版本升级”章节。
